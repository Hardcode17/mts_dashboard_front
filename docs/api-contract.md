# API-контракт для фронтенда

Источник истины для реализованных маршрутов — [OpenAPI в Hardcode17/mts_dashboard_backend](https://github.com/Hardcode17/mts_dashboard_backend/blob/main/docs/dashboard-api.openapi.yaml). Сценарии координатора и ожидаемое поведение интерфейса описаны в [требованиях Hardcode17/mts_dashboard_data](https://github.com/Hardcode17/mts_dashboard_data/blob/main/docs/requirements.html).

| Операция | Маршрут |
|---|---|
| Список инцидентов и счётчики групп | `GET /api/dashboard/incidents` |
| Карточка по номеру INC | `GET /api/dashboard/incidents/{incidentId}` |
| Состояние опубликованного снимка | `GET /api/snapshot/status` |
| Текущий координатор | `GET /api/me` |
| Готовность бэкенда | `GET /health` |

- Счётчики берутся из `groups[].incidentCount` первой страницы. Принадлежность строки — из `groupMemberships`. Один INC может входить в несколько групп.
- Курсор списка действует в пределах одной публикации. Клиент собирает страницы в один снимок, проверяет `revision` и `eventSeq` и опрашивает первую страницу с её `ETag`. При ошибке остаётся доступен последний успешно собранный снимок.
- Клиент запрашивает завершённые карточки для общего списка и счётчика движения. В группах отображается только серверная классификация.
- Список содержит продукт, статус, назначенную группу, время регистрации и срок. Заголовок, официальный исполнитель, остаток SLA и ссылка ITSM приходят из карточки. Отсутствующий срок отображается явно.
- Реальный режим использует публичный клиент Keycloak `dashboard-web`: Authorization Code, PKCE S256 и Bearer JWT с аудиторией `dashboard-api`. `/api/me` проверяет сеанс и возвращает личность координатора.
- В сборке для деплоя запросы проходят через прокси к бэкенду. Локальный мок обслуживает этот же формат чтений и отдельно поддерживает сценарии демонстрации.

Редактирование карточки требует маршрутов KAN-58 в развёрнутом бэкенде. Серверный журнал значимых событий и точное подтверждение ожидают KAN-25 и KAN-29. До их готовности рабочий источник проверяется периодическим опросом опубликованного снимка.
