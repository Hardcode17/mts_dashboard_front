# Gravity UI × МТС

> Исходный пакет дизайна. Рабочая копия темы для приложения находится в
> `src/theme/`: `mts-theme-v2.css` подключён как `mts-theme.css`, рядом лежат
> `fonts.css`, `mts-navigation.css` и `fonts/`. Этот каталог в сборку не попадает
> и служит справочником и автономным предпросмотром.

Тема на основе предоставленного styles.json. Фирменные веб-шрифты взяты из архива МТС, без конвертации. Гайдлайны использованы как справочный материал по стилю.

## Что подключать

- `styles.json` — тема в формате исходного файла: все 533 исходных токена сохранены, добавлен токен семейства заголовков.
- `mts-theme.css` — готовая CSS-тема для структуры токенов исходного файла. Проверена на `@gravity-ui/uikit 6.43.4`.
- `styles-v2.json` — экспорт для редактора на `@gravity-ui/uikit-themer 2.1.0`: новые токены и удалённые устаревшие переменные обработаны генератором.
- `mts-theme-v2.css` — CSS для новой структуры тем UIKit 7 / Themer 2. Проверен разбор JSON и повторный экспорт; визуальный пример собран на UIKit 6.
- `fonts.css` и `fonts/` — шрифты MTS Text и MTS Wide в начертаниях Regular, Medium, Bold.
- `preview/index.html` — автономный интерактивный пример на настоящих компонентах Gravity UI. Открывается локально без сборки и без CDN.
- `preview-light.png`, `preview-dark.png` — снимки предпросмотра.

Выберите одну пару JSON/CSS под свою версию. Не подключайте обе CSS-темы одновременно. Если версия проекта неизвестна, начните с `mts-theme.css`: она соответствует структуре присланного JSON.

## Подключение в React

Скопируйте `mts-theme.css`, `fonts.css`, `mts-navigation.css` и папку `fonts/` вместе, сохранив относительные пути. Например, в `src/theme/`.

```tsx
import {ThemeProvider} from '@gravity-ui/uikit';
import '@gravity-ui/uikit/styles/styles.css';
import './theme/mts-theme.css';

export function App() {
  return (
    <ThemeProvider theme="light">
      {/* Ваш интерфейс на Gravity UI */}
    </ThemeProvider>
  );
}
```

Для тёмного варианта укажите `theme="dark"`. Тема использует штатные классы `.g-root`, `.g-root_theme_light` и `.g-root_theme_dark`; компонентные переопределения и `!important` не нужны. Для UIKit 7 используйте `mts-theme-v2.css` вместо `mts-theme.css`.

CSS уже импортирует `fonts.css` и `mts-navigation.css`. Если сборщик не обрабатывает CSS `@import`, удалите обе строки `@import` из темы и явно импортируйте `fonts.css` и `mts-navigation.css` после темы. Шрифты должны раздаваться вместе с приложением. Отдельно устанавливать их в операционную систему не требуется.

JSON содержит значения токенов, но не файлы шрифтов: при импорте в редактор подключение шрифтов остаётся отдельным шагом. В рабочем приложении используйте CSS и вложенные WOFF2.

## Визуальные решения

- Палитра бренда строится от `#FF0032`. Основные кнопки используют `#E6002D`: контраст с белым текстом выше 4.5:1. Наведение — `#CC0028`.
- Ссылки — тёмно-красные в светлой теме и светло-красные в тёмной. Выделение — полупрозрачный красный.
- MTS Text Regular — основной текст и контролы; MTS Text Medium — подзаголовки; MTS Wide Medium — заголовки и крупные значения. Моноширинный текст сохраняет системный monospace.
- Светлая тема: белый фон, поверхности `#F2F3F7`, текст `#1D2023`. Тёмная: фон `#141417`, поверхности `#232329`, текст `#F2F3F7`.
- Скругления: 4 / 6 / 8 / 12 / 16 px. Размеры текста и межстрочные интервалы исходной темы сохранены, чтобы плотные интерфейсы оставались удобными.
- Успех, предупреждение, информация и ошибка остаются разными семантическими состояниями. Цвета текста статусов скорректированы для обеих тем.

## Предпросмотр и границы темы

В примере работают поиск, вкладки, создание демонстрационной строки, переключение темы, селект, чекбокс и переключатель. Таблица адаптируется прокруткой на узких экранах.

Сетка, боковая навигация, карточки и композиция страницы относятся к демонстрации; файл темы задаёт токены существующих компонентов. Тема не перестраивает автоматически разметку приложения и не перекрашивает произвольные графики или сторонние компоненты со своими фиксированными цветами.

Символ МТС в демонстрации выделен из предоставленного SVG «МТС ID» с сохранением исходной геометрии и цветов. Другие продуктовые логотипы в пакет не включены.

## Выбранная иконка в боковой панели

`mts-navigation.css` делает выбранную иконку AsideHeader светлой в тёмной теме. Файл автоматически подключается обеими CSS-темами. Обычные пункты и светлая тема не меняются.

В предпросмотре на gravity-ui.com выбранная иконка специально окрашивается в `--g-color-base-background`, то есть в цвет фона страницы. Это правило самого сайта, его нельзя исправить импортом JSON без изменения фона всей темы. Поэтому JSON-файлы оставлены прежними. Для исправления в своём приложении используйте CSS-тему; на странице редактора понадобится добавить `mts-navigation.css` отдельно в стили страницы.

Источник правила: https://github.com/gravity-ui/landing/blob/main/src/components/UISamples/PreviewLayout/PreviewLayout.scss .
